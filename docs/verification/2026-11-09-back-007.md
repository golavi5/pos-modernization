## Findings

1. **App-wide invisible text (fixed in #75).** The inventory table headers and the movement reference/notes rendered near-white on white (`rgb(244 244 245)`). Cause: `text-secondary`/`text-tertiary` (148 uses) did not read the text-hierarchy tokens. The movements list had never rendered before (its page params returned 400), so nobody had seen it. Screenshot `back-007-10-movements-settled.png` shows the bug as found; the headers in `back-007-04-inventory.png` too.
2. The edit panel in `back-007-03-edit-form.png` is captured mid slide-in, so it looks cropped; the assertions in rows 3–4 ran against the settled form.
